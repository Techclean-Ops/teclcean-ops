Google Sheets Connection

Step 1: Create a Google Sheet. Add tabs named: Auckland, Wellington, Christchurch, Staff, Log

Step 2: Extensions → Apps Script → paste the script below → Deploy as Web App (execute as: Me, access: Anyone with Google Account)

Step 3: Copy the deployed Web App URL into the field below and click Connect.

⬤ Not connected — data stored locally in browser

WorkflowMax Connection

Jobs set to Scheduled or In Progress in WorkflowMax are added here automatically every 10 minutes (branch and class from the WorkflowMax custom fields), marked 📥 needs crew. Invoiced / closed jobs are marked $ Invoiced. Read-only — nothing is written back to WorkflowMax.
Set-up (once): add the wfm script file (techclean_wfm_v2.gs) to the Apps Script project → put the Client ID / Secret in Script Properties → redeploy → open the web app URL with ?action=wfmAuth → approve → run wfmInstallTrigger.

Job Lists — Managers & Clearance Assessors

One name per line, per branch. These fill the TechClean manager and Clearance assessor dropdowns on each job and sync to every device. You can also just type a new name into the job form — it's added to that branch's list when the job is saved.

Force Overwrite (Admin)

Makes this device the master copy: pushes its current schedule and staff list up to the Sheet (overwriting the roster there), then clears this device's cache and reloads fresh from the Sheet. Use it from a device you know is correct whenever data looks out of sync.

Access PIN

Change the 4-digit PIN all staff use to access the app. Share the new PIN with your team after changing it.

Admin PIN — required to access Setup

The admin PIN is separate from the staff PIN. Only administrators who need to change settings, manage staff, or connect Google Sheets need this PIN.

Default admin PIN: 9999
